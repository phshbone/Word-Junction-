# Word Junction

A lightweight vocabulary PWA built around one useful connection at a time.

## Core interaction
- Start with one anchor word.
- Explore a similar word or an opposite.
- See what connects the two and how they differ.
- Make either connected word the next anchor.
- Save useful pairings locally.
- Works offline after first load.

## Product rule
**Never overwhelm the learner with vocabulary. Teach one connection at a time.**

No framework, account, paid API, or backend is required.
